九、UX 体验评价

✅ 做得好的

  • 引导流程：首次访问有 Onboarding 浮层 + 3 个 Demo 案例，一键填入需求降低使用门槛
  • 产品图谱：信息密度高且有层次（分类 tab + 产品列表 + 右侧导航 + 热门推荐），专业感强
  • 主题系统：4 种主题即时切换，视觉个性化好
  • 侧边栏导航：图标 + 文字清晰，当前页高亮明确，收起/展开流畅
  • Agent 澄清机制：输入不足时主动追问细节（如设备数量/损失规模），体验接近真人员工

⚠️ 可改进的

  • 文档数显示：底部 "文档 --" 给人"未加载完"的感觉。部署 f266847 后应立即改善
  • 匿名态引导不足：仪表盘/历史/知识库点击后直接弹登录框，可考虑先展示预览 + "登录查看更多"的渐进式引导
  • 匹配模式标签：标准/Agent/向导三个 mode-option 用的是 span 而非 button，在 accessibility tree 中不可见（不影响鼠标用户，但不利于无障碍访问）
  • Demo 案例默认走 Agent 模式：选择 Demo 后默认进入 Agent（体验）模式，而 Agent 强制登录。新用户选了 Demo 却被拦在登录墙外，可考虑 Demo 默认走"标准"模式（匿名可用）
