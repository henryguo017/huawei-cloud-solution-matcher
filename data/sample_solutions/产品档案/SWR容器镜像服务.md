# SWR 容器镜像服务（Software Repository for Container）

## 一、产品定位
SWR 是华为云提供的容器镜像全生命周期托管服务，相当于企业私有的"Docker Hub / Harbor"。它负责镜像的安全存储、分发、漏洞扫描与多地域同步，是容器化 DevOps 流水线的核心枢纽。与 CCE（云容器引擎）/ CCI（云容器实例）深度集成，镜像是容器应用运行的"源代码"，SWR 就是存放和管理这些"源代码"的仓库。

## 二、核心能力
1. **OCI / Docker 镜像托管**：兼容标准 Docker 镜像格式，支持镜像上传、下载、版本标签管理。
2. **镜像安全漏洞扫描**：自动对镜像层进行 CVE 漏洞扫描，阻断含高危漏洞的镜像入库。
3. **企业级 Harbor 仓库**：支持组织（Organization）与多租户隔离，适配企业级权限治理。
4. **跨区域镜像同步复制**：镜像可跨 Region 自动同步，支撑多地域容器部署。
5. **镜像加速分发**：全球加速节点 + P2P 拉取，镜像下载速度提升约 10 倍。
6. **镜像签名与验签**：支持内容信任（镜像签名），防止镜像被篡改。
7. **生命周期策略**：自动清理过期镜像标签，节省存储。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：K8s 集群镜像分发**
  - 痛点：自建镜像仓库运维重、跨地域拉取慢、镜像安全无保障。
  - 方案：把镜像推到 SWR，CCE/CCI 直接从 SWR 拉取，开启漏洞扫描。
  - 价值：免运维、拉取快 10 倍、高危镜像入库即拦截。
- **场景2：CI/CD 流水线镜像构建**
  - 痛点：开发构建出的镜像无处存放、无版本管理。
  - 方案：CodeHub 提交代码 → 流水线构建镜像 → 推送 SWR → CCE 部署。
- **场景3：企业内部镜像市场**
  - 痛点：各团队重复造轮子，基础镜像不一致。
  - 方案：在 SWR 建立组织级基础镜像库，统一分发。

## 四、常见搭配
- 与 **CCE 云容器引擎 / CCI 云容器实例** 零配置对接（容器运行时直接从 SWR 拉镜像）。
- 与 **CodeHub 代码托管 / ServiceStage** 搭配（代码→镜像→部署流水线）。
- 与 **DEW 密钥管理** 搭配（镜像签名密钥托管）。
