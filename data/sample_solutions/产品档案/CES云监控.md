# CES 云监控（Cloud Eye Service）

## 一、产品定位
CES 是华为云统一的资源监控与告警服务，相当于云上所有资源的"健康仪表盘"。它实时监控 ECS、数据库、网络、存储等 40+ 种云资源的运行指标，提供自定义 Dashboard、阈值告警、通知推送、API 导出，帮助企业掌握资源运行状态、及时发现异常。是运维可观测性的第一层（Metrics），与 LTS（日志）、APM（应用性能）共同构成可观测体系。

## 二、核心能力
1. **40+ 云产品监控指标采集**：开箱即用，无需额外部署。
2. **自定义监控 Dashboard**：拖拽式搭建监控大屏。
3. **多类告警**：阈值 / 趋势 / 事件告警。
4. **多渠道通知**：邮件 / 短信 / HTTP 推送给 SMN 等。
5. **Agentless 无侵入采集**：基础指标免装 Agent。
6. **自定义上报指标（PutMetric）**：业务自定义指标接入。
7. **告警抑制与静默**：避免告警风暴。
8. **与 SMN / LTS 联动**：告警进 SMN、详情入 LTS。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：云资源运行状态大盘**
  - 痛点：资源多了，状态靠肉眼看不过来。
  - 方案：CES Dashboard 一屏看全部资源关键指标。
  - 价值：异常一眼可见，值班效率提升。
- **场景2：业务性能基线监控**
  - 痛点：CPU/内存突高无感知，直到宕机。
  - 方案：设阈值告警，超基线即短信通知。
- **场景3：SLA 达标率统计**
  - 痛点：客户问 SLA，拿不出数据。
  - 方案：CES 历史数据导出，统计可用性。

## 四、常见搭配
- 与 **ECS / RDS 等** 搭配（被监控资源）。
- 与 **SMN 消息通知** 搭配（告警推送渠道）。
- 与 **LTS 日志服务** 搭配（指标异常时联动查日志）。
- 与 **CES 告警触发函数（FunctionGraph）** 搭配（自动扩缩容响应）。
