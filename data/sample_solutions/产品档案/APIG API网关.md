# APIG API 网关（API Gateway）

## 一、产品定位
APIG 是华为云的企业级高性能 API 网关，提供 API 从"设计 → 发布 → 运维 → 下线"的全生命周期管理。它是微服务架构和开放平台的统一流量入口，负责请求路由、协议转换、流量控制、身份认证与安全防护。简单说，APIG 是"所有对外的 API 请求都要先过的那道门"——统一管入口、管安全、管流量。

## 二、核心能力
1. **多协议支持**：RESTful / gRPC / WebSocket，满足 Web、移动端、IoT 不同接入需求。
2. **API 全生命周期管理**：可视化设计、发布、版本管理、灰度发布、下线。
3. **流量控制与限流熔断**：按 API / 用户 / 应用维度限流，保护后端不被突发流量打垮。
4. **请求签名与鉴权**：支持 HMAC / AKSK 签名、OAuth2.0 授权，与 IAM 深度集成做统一身份校验。
5. **请求 / 响应转换与 Mock**：协议转换、字段映射、Mock 调试，前后端并行开发。
6. **调用链追踪与日志分析**：全链路监控、访问日志、调用统计。
7. **自定义插件**：支持 Python / Node.js 插件扩展，满足个性化逻辑。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：微服务统一 API 入口**
  - 痛点：几十个微服务各自暴露端口，前端对接混乱、无统一安全。
  - 方案：所有微服务经 APIG 统一发布，前端只对接 APIG 域名。
  - 价值：入口收敛、统一鉴权、统一限流，前端对接成本大降。
- **场景2：开放平台对外开放 API**
  - 痛点：企业要向合作伙伴开放能力，但缺乏计量、鉴权、流控手段。
  - 方案：APIG 做能力开放网关，AKSK 鉴权 + 调用计量 + 流量套餐。
- **场景3：移动 App / IoT 设备后端网关**
  - 痛点：海量设备 / 客户端直连后端，无流控易雪崩。
  - 方案：设备 / App 请求统一走 APIG，按设备 / 用户限流。

## 四、常见搭配
- 与 **CCE / CCI 容器** 搭配（后端服务跑在容器，APIG 做入口）。
- 与 **IAM 统一身份认证** 搭配（APIG 把请求交给 IAM 做统一鉴权）。
- 与 **CSE 微服务引擎 / ServiceStage** 搭配（微服务治理 + 统一网关入口）。
- 与 **SMN / LTS** 搭配（API 调用日志入 LTS、异常告警入 SMN）。

## 五、公开参考价（华北-北京四，2026 口径，⚠部分待官网复核）
- 基础型（约 100 万次/天）：约 **¥3000/月/实例**。
- 专业型 / 企业型规格更高，单价更高；也支持**按调用次数阶梯计费**。
- 计费模式：包月实例费 + 调用量（按量部分）。
- 选型建议：先按日均调用量选规格，突发流量用限流保护后端。

## 六、售前话术要点
- 客户问"几十个服务怎么对外"——答：APIG 做统一网关，一个域名管所有 API，鉴权、限流、监控一步到位。
- 强调安全：签名验证 + 流控 + 与 IAM 联动鉴权，防刷防爬防雪崩。
- 强调开放：要做开放平台 / 能力开放，APIG 是标配入口，自带计量和套餐。
