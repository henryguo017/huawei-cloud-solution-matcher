# DAS 数据管理服务（Data Admin Service）

## 一、产品定位
DAS 是华为云面向数据库的一站式管理运维平台，相当于 DBA 的"Web 工作台"。它提供实例管理、SQL 窗口、慢 SQL 分析、性能诊断、容量预估、SQL 审核等能力，支持 MySQL / PostgreSQL / SQL Server / GaussDB 等多引擎。DBA 无需安装客户端，通过浏览器即可完成日常运维，大幅提升数据库管理效率，并降低误操作风险。

## 二、核心能力
1. **多引擎统一管理**：一个平台管 MySQL / PostgreSQL / SQL Server / GaussDB。
2. **实时性能监控与诊断**：QPS / 连接数 / 锁等待一眼看，AI 根因分析。
3. **慢 SQL 分析**：语句级定位慢查询，给出索引 / 改写建议。
4. **SQL 智能审核**：200+ 审核规则，上线前拦截高危 SQL。
5. **在线 DDL 无锁变更**：大表结构变更不锁表，业务无感。
6. **实例会话管理**：Kill 异常会话、排查锁等待。
7. **容量预估与扩容建议**：趋势预测，提前规划存储。
8. **备份恢复管理**：可视化备份策略与恢复。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：DBA 日常运维工作台**
  - 痛点：多类型数据库、多实例，客户端来回切，效率低。
  - 方案：DAS 统一纳管，Web 控制台操作。
  - 价值：一个工作台管 1000+ 实例，效率倍增。
- **场景2：SQL 开发与审核流程**
  - 痛点：开发直接在生产跑 SQL，易误删。
  - 方案：DAS SQL 审核 + 权限审批，高危操作拦截。
- **场景3：数据库性能问题排查**
  - 痛点：线上慢，定位不到 SQL。
  - 方案：DAS 慢 SQL 分析到语句级，给优化建议。

## 四、常见搭配
- 与 **RDS / GaussDB / DDS** 搭配（被管数据库实例）。
- 与 **CES / LTS** 搭配（指标与日志联动分析）。
- 与 **DEW** 搭配（凭据安全托管连接）。
