# DEW 密钥管理（Data Encryption Workshop）

## 一、产品定位
DEW 是华为云的专业密钥管理服务（KMS），提供密钥的全生命周期管理与硬件安全模块（HSM）保护。它把密码学能力封装成一行业务代码就能调用的 API，让开发者无需成为密码学专家也能给数据加密、签名、保护凭据。适用于数据库加密、对象存储加密、磁盘加密、支付 PIN 保护、合规脱敏等场景，是数据安全的"保险柜 + 钥匙管理"。

## 二、核心能力
1. **HSM 硬件安全模块保护**：密钥在专用 HSM 集群内生成与运算，密钥永不以明文离开硬件。
2. **对称 / 非对称密钥管理**：AES / SM 系列算法，支持签名验签。
3. **密钥自动轮换**：按策略定期轮换，降低密钥泄露风险。
4. **信封加密（Envelope）**：用数据密钥加密数据、主密钥加密数据密钥，兼顾安全与性能。
5. **凭据管理**：数据库密码、API 密钥等敏感凭据安全托管，避免硬编码。
6. **跨区域密钥复制**：满足异地容灾的密钥同步。
7. **BYOK 自带密钥**：企业可导入自有密钥材料。
8. **审计日志**：密钥使用全程留痕。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：数据库 TDE 透明加密**
  - 痛点：敏感数据落盘明文，合规不达标。
  - 方案：RDS / GaussDB 开启 TDE，密钥由 DEW 托管。
  - 价值：数据静态加密，满足等保 / GDPR，无应用改造。
- **场景2：OBS / EVS 服务端加密**
  - 痛点：存储数据需加密合规。
  - 方案：OBS 服务端加密、EVS 加密盘，密钥 DEW 托管。
- **场景3：支付 / 敏感凭据保护**
  - 痛点：数据库密码硬编码在代码里，泄露风险高。
  - 方案：凭据托管到 DEW，应用运行时动态获取。

## 四、常见搭配
- 与 **RDS / GaussDB** 搭配（TDE 透明加密）。
- 与 **OBS / EVS** 搭配（存储服务端加密）。
- 与 **IAM** 搭配（密钥访问权限由 IAM 管控）。
- 与 **WAF / HSS** 区分：DEW 管"数据加密密钥"，安全服务管"攻击防护"。
