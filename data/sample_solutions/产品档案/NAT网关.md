# NAT 网关（NAT Gateway）

## 一、产品定位
NAT 网关是华为云为虚拟私有云（VPC）内实例提供的公网访问与地址转换服务。它让 VPC 中无公网 IP 的云服务器（如 ECS、BMS、容器节点）能够安全地访问互联网（出公网），同时支持通过端口映射将内网服务暴露给公网（入公网）。核心价值是"多台实例共享少量弹性公网 IP（EIP）出公网"，在不牺牲安全隔离的前提下显著降低公网带宽成本。

## 二、核心能力
1. **SNAT 源地址转换**：VPC 内多个私有 IP 共享一个或多个 EIP 访问公网，对外只暴露 EIP。
2. **DNAT 目标地址转换**：将 EIP 的指定端口映射给内网某台实例，实现"无公网 IP 也能被公网访问"（如暴露一台堡垒机/游戏服）。
3. **端口级规则粒度**：SNAT/DNAT 规则可精确到子网、网段、端口，灵活控制哪些流量走 NAT。
4. **多 EIP 共享与故障切换**：单网关最多绑定 20 个 EIP，支持自动故障切换，避免单 EIP 成为瓶颈。
5. **高吞吐高性能**：单网关最大 5Gbps 带宽，支持千万级并发连接，满足大流量出公网场景。
6. **跨可用区高可用**：网关跨 AZ 部署，自动故障切换，业务无感知。
7. **IPv4/IPv6 双栈**：支持双栈地址转换。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：多台 ECS 统一出公网做软件包更新/数据回传**
  - 痛点：每台 ECS 都绑 EIP 成本高、IP 资产难管理、暴露面广。
  - 方案：VPC 内 ECS 不绑公网 IP，统一经 NAT 网关 SNAT 出公网。
  - 价值：公网 IP 数量从 N 降到 1~2 个，公网成本下降约 70%，攻击面收窄。
- **场景2：数据库只读副本跨公网与主库同步**
  - 痛点：只读副本需访问公网源，但不希望直接暴露公网 IP。
  - 方案：只读副本经 NAT SNAT 出公网拉取，不分配独立 EIP。
- **场景3：内网服务需被公网有限访问（如运维跳板机）**
  - 痛点：跳板机要被远程连，但又不想整台机器长期暴露。
  - 方案：DNAT 把 EIP 的某个高位端口映射到跳板机 22 端口。

## 四、常见搭配
- 与 **VPC 虚拟私有云** 强绑定（NAT 必须建在 VPC 内）。
- 与 **EIP 弹性公网IP** 搭配（NAT 需绑定 EIP 才有出公网能力；共享带宽可进一步降本）。
- 与 **ECS / CCE 容器集群** 搭配（集群节点统一经 NAT 出公网，避免节点直接绑 EIP）。
- 与 **ELB 弹性负载均衡** 区分：对外提供服务的入口用 ELB，内部统一出公网用 NAT。

## 六、售前话术要点
- 客户问"我的服务器怎么上外网又不被攻击"——答：用 NAT 网关做 SNAT，服务器不绑公网 IP，只暴露 NAT 的 EIP，省钱又收窄攻击面。
- 客户算成本：强调"多台共用 1 个 EIP，公网成本降 70%"。
- 强调高可用：跨 AZ 部署、千万级并发连接，适配电商大促、批量任务回传等突发出网。
