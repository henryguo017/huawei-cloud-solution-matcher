# SMN 消息通知（Simple Message Notification）

## 一、产品定位
SMN 是华为云的消息通知服务，提供可靠的消息传递能力，是云上"事件触达"的神经末梢。它支持短信、邮件、HTTP/HTTPS、FunctionGraph 等多种推送渠道，既可作为云服务的告警通知通道（如 CES 告警、LTS 日志告警），也可作为业务系统的消息中间件，支撑告警通知、营销触达、状态同步等场景。Topic 订阅发布模型让消息一对多可靠送达。

## 二、核心能力
1. **多渠道通知**：短信（国内 / 国际）、邮件（HTML / 文本）、HTTP/HTTPS Webhook、FunctionGraph 函数触发。
2. **消息主题（Topic）订阅发布**：发布一条、多订阅者并行接收。
3. **消息模板与变量替换**：营销短信批量个性化。
4. **消息队列死信处理**：推送失败重试，保证可达。
5. **发送记录与统计**：投递状态可查。
6. **跨区域消息可达**。
7. **与 CES / LTS / CloudTrigger 联动**：事件驱动自动通知。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：云资源告警短信 / 邮件通知**
  - 痛点：资源异常无人知晓。
  - 方案：CES 告警 → SMN 短信 / 邮件推值班人。
  - 价值：异常秒级触达，快速响应。
- **场景2：业务系统异常触达**
  - 痛点：关键业务事件需通知相关人。
  - 方案：业务事件发布到 SMN Topic，多系统订阅。
- **场景3：用户营销短信 / 邮件**
  - 痛点：需批量触达用户。
  - 方案：SMN 模板短信 + 变量，个性化群发。

## 四、常见搭配
- 与 **CES 云监控** 搭配（告警推送主渠道）。
- 与 **LTS 日志服务** 搭配（日志告警通知）。
- 与 **FunctionGraph 函数** 搭配（消息触发函数自动处理）。
- 与 **HSS / WAF** 搭配（安全事件通知）。
