# VPN 网关（VPN Gateway）

## 一、产品定位
VPN 网关是华为云基于 IPsec VPN 协议，在企业本地数据中心（IDC）/ 分支机构与华为云 VPC 之间建立加密隧道的服务，是企业上云"混合云组网"最经济、最易落地的第一跳。相比专线（如云连接 / 专线），VPN 以互联网公网为基础，成本极低，适合数据量中等、对延迟不极端敏感、且需要满足等保加密传输的互联场景。

## 二、核心能力
1. **IPsec VPN 加密隧道**：基于标准 IPsec 协议，支持 IKEv1 / IKEv2 密钥协商，数据全程加密传输。
2. **主备双链路冗余**：支持主备两条隧道热备，链路故障自动切换，保障业务连续性（RPO 接近 0）。
3. **BGP 动态路由**：支持 BGP 动态路由协议，自动学习对端路由，减少手工配置。
4. **国密算法支持**：支持 SM2 / SM3 / SM4 国密算法，满足政务、金融等强合规行业的加密要求。
5. **多种认证方式**：预共享密钥（PSK）、证书认证。
6. **Hub-Spoke 多点组网**：支持总部 Hub 与多分支 Spoke 的星型互联。
7. **DPD 死亡对端检测**：自动探测对端存活，断链快速感知。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：IDC 上云混合云互联**
  - 痛点：本地机房有核心系统，上云过渡期需与云上系统互访，专线太贵。
  - 方案：本地防火墙 / VPN 设备与华为云 VPN 网关建立 IPsec 隧道。
  - 价值：分钟级打通，成本比专线低 80%+，满足加密合规。
- **场景2：异地容灾备份链路**
  - 痛点：核心数据库需异地备份，但带宽不大、成本高敏感。
  - 方案：通过 VPN 隧道做备份数据异步复制。
- **场景3：分支机构接入总部 VPC**
  - 痛点：多地分支需安全访问总部云上系统。
  - 方案：各分支 VPN 设备与总部 Hub VPN 网关建立 Spoke 隧道。

## 四、常见搭配
- 与 **VPC 虚拟私有云** 搭配（VPN 网关建在 VPC 内，打通本地与云上私网）。
- 与 **ECS / RDS / GaussDB** 搭配（本地应用经 VPN 直接访问云上数据库 / 应用）。
- 与 **NAT 网关** 区分：VPN 解决"本地↔云上"私网加密互联；NAT 解决"云内↔公网"出网。
- 高要求低延迟场景可叠加 **云连接 / 专线** 作为主链路，VPN 作备份链路。
