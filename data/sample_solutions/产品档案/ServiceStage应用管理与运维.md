# ServiceStage 应用管理与运维平台（ServiceStage）

## 一、产品定位
ServiceStage 是华为云一站式应用管理与运维平台，面向应用开发者提供"应用托管部署、灰度发布、自动化运维、性能管理（APM）"的全链路能力。它向上屏蔽底层 K8s / 容器 / 函数的复杂性，让开发者专注业务代码，向下与 CCE / CCI / CodeHub 深度集成，是"应用生命周期的操作台"。支持容器应用与 Serverless 应用统一管理。

## 二、核心能力
1. **应用全托管部署**：支持容器应用、无服务器（FaaS）应用统一托管，免运维底层集群。
2. **滚动 / 灰度 / 蓝绿发布**：多种发布策略，降低上线风险。
3. **自动化扩缩容**：按 CPU / 自定义指标自动扩缩，应对流量波动。
4. **健康检查与自愈**：实例异常自动重启 / 替换。
5. **APM 应用性能监控**：内置应用性能管理，定位慢接口、慢 SQL。
6. **日志集中采集与分析**：与 LTS 联动采集应用日志。
7. **CI/CD 流水线一键部署**：与 CodeHub 打通，提交即发布。
8. **成本分析与资源优化**：资源用量可视化，推荐降本方案。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：Web 应用托管与运维**
  - 痛点：自建 K8s 运维重，开发不想管集群。
  - 方案：应用托管到 ServiceStage，只提交镜像 / 代码。
  - 价值：零集群运维，获得发布、监控、扩缩容一体化能力。
- **场景2：DevOps 持续交付落地**
  - 痛点：交付流程割裂，发布靠手工。
  - 方案：CodeHub 提交 → ServiceStage 流水线自动构建发布。
- **场景3：应用性能瓶颈诊断**
  - 痛点：线上慢，但不知瓶颈在哪。
  - 方案：APM 自动拓扑 + 调用追踪，定位到具体方法。

## 四、常见搭配
- 与 **CCE / CCI 容器** 搭配（底层运行时，ServiceStage 做应用编排）。
- 与 **CodeHub 代码托管** 搭配（CI/CD 流水线）。
- 与 **CSE 微服务引擎** 搭配（微服务应用治理 + 部署）。
- 与 **APM / LTS / CES** 搭配（可观测性三件套）。

## 五、公开参考价（华北-北京四，2026 口径，已核验）
