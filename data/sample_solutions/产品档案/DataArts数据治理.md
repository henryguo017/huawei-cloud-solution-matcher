# DataArts 数据治理（DataArts Studio）

## 一、产品定位
DataArts Studio 是华为云的一站式数据治理中心，覆盖"数据开发、数据质量、数据目录、数据安全、数据服务"全链路，是企业构建"数据中台 / 数据资产体系"的核心平台。它把数据建模、ETL 编排、元数据管理、数据血缘、数据质量、数据服务 API 化全部打通，让分散的数据变成可信赖、可共享、可变现的资产。相当于企业数据的"中央厨房 + 资产登记处"。

## 二、核心能力
1. **数据建模**：维度 / 事实 / 汇总表可视化建模。
2. **可视化 ETL 编排（DAG）**：拖拽式开发数据加工任务。
3. **数据质量规则与检核**：200+ 内置规则模板，自动质检。
4. **元数据管理与数据目录**：自动盘点数据资产，形成数据地图。
5. **数据血缘自动追踪**：字段级全链路血缘，影响分析。
6. **数据安全分级分类**：敏感数据自动识别与分级。
7. **数据服务 API 自动生成**：治理成果一键发布为 API。
8. **与 DWS/DLI/GaussDB 深度集成**：数据加工链路闭环。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：企业数据中台建设**
  - 痛点：数据散落各系统，口径不一、找不到、不敢用。
  - 方案：DataArts 统一建模 + 开发 + 质量 + 目录。
  - 价值：数据可信、可查、可共享，支撑经营决策。
- **场景2：数据仓库建模与 ETL 开发**
  - 痛点：数仓开发靠脚本，难维护。
  - 方案：DataArts 可视化 DAG 编排，版本管理。
- **场景3：监管报送数据治理**
  - 痛点：监管要求数据可追溯、口径统一。
  - 方案：数据血缘 + 质量规则满足报送合规。

## 四、常见搭配
- 与 **DWS 数据仓库 / DLI 数据湖** 搭配（加工目标存储）。
- 与 **OBS** 搭配（原始数据湖底座）。
- 与 **ROMA 应用与数据集成** 搭配（集成入湖后做治理）。
- 与 **CloudTable** 搭配（治理后画像数据落地）。
