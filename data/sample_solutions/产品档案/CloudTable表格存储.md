# CloudTable 表格存储（CloudTable）

## 一、产品定位
CloudTable 是华为云基于 Apache HBase / OpenTSDB 等开源生态构建的分布式 NoSQL 数据库服务，提供海量结构化 / 半结构化数据的存储与查询能力。它面向"超大规模、超低延迟、schema 灵活"的大数据场景，是时序数据、用户画像、社交图谱、监控指标的理想存储底座。存算分离架构让存储与计算独立扩展，应对 PB 级数据游刃有余。

## 二、核心能力
1. **HBase 兼容宽表模型**：海量 KV / 宽表存储，TB~PB 级。
2. **OpenTSDB 时序模型**：专为监控指标、IoT 时序数据优化。
3. **PB 级自动水平扩展**：存算分离，存储计算独立线性扩展。
4. **毫秒级读写延迟**：分布式索引，P99 < 5ms。
5. **多版本与 TTL 自动过期**：数据按版本保留、自动清理冷数据。
6. **冷热数据分层存储**：热数据 SSD、冷数据降成本。
7. **二级索引加速查询**。
8. **与 DLI / MRS / HDFS 无缝互通**：融入大数据生态。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：IoT 设备时序数据存储**
  - 痛点：千万设备每秒上报，关系库扛不住、查询慢。
  - 方案：设备时序数据写入 CloudTable（OpenTSDB）。
  - 价值：百万级 TPS 写入、毫秒查询，扩容无需停机。
- **场景2：用户行为轨迹与画像**
  - 痛点：用户行为宽表列多、增长快。
  - 方案：HBase 宽表存储用户画像，列动态扩展。
- **场景3：监控指标与日志**
  - 痛点：监控指标高频写入、需快速聚合。
  - 方案：OpenTSDB 存储指标，对接 Grafana 可视化。

## 四、常见搭配
- 与 **DWS 数据仓库 / MRS 大数据** 搭配（冷热数据分层、批流一体）。
- 与 **DLI 数据湖探索** 搭配（联邦查询 CloudTable）。
- 与 **IoTDA 设备接入** 搭配（设备数据落 CloudTable）。

## 五、公开参考价（华北-北京四，2026 口径，⚠部分待官网复核）
