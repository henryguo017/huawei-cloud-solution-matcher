# ROMA 应用与数据集成（ROMA Connect）

## 一、产品定位
ROMA Connect 是华为云的企业级应用与数据集成平台，解决企业"IT 系统孤岛"问题。它提供 API 编排、数据集成、消息集成、能力开放四大核心能力，内置 300+ 预置连接器（覆盖 ERP / CRM / 数据库 / 消息队列 / SaaS），通过低代码拖拽即可打通异构系统，让数据在系统间自由流动、能力可复用。是政企"数字化转型、系统互联"的关键枢纽。

## 二、核心能力
1. **API 全生命周期管理**：设计、发布、治理、能力开放。
2. **数据集成**：实时 / 批量 / 增量多种模式，断点续传、数据一致性保障。
3. **消息集成**：MQTT / Kafka / RabbitMQ 等多协议消息桥接。
4. **300+ 预置连接器**：ERP（SAP/Oracle）、CRM、数据库、SaaS 即插即用。
5. **低代码 / 零代码编排**：拖拽式集成流，业务人员可上手。
6. **数据转换与映射（ETL）**：字段级转换、格式适配。
7. **API 资产市场**：集成成果沉淀为可复用 API 资产。
8. **多租户与权限隔离**：企业级安全治理。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：ERP/CRM/OA 系统间数据同步**
  - 痛点：各系统割裂，数据靠人工导出导入，错漏多。
  - 方案：ROMA 拖拽编排，定时 / 实时同步数据。
  - 价值：数据自动流动，打通信息孤岛，效率提升数倍。
- **场景2：遗留系统 API 化改造**
  - 痛点：老系统无接口，无法对接新平台。
  - 方案：ROMA 把老系统包装成标准 API。
- **场景3：开放平台 / 开放银行 API**
  - 痛点：对外能力缺乏统一编排与计量。
  - 方案：ROMA 做能力开放网关 + 资产市场。

## 四、常见搭配
- 与 **RDS / 数据库** 搭配（数据源接入）。
- 与 **OBS** 搭配（文件类数据集成落地）。
- 与 **APIG API 网关** 区分：ROMA 重"系统间集成编排"，APIG 重"API 入口治理"，可互补。
- 与 **DataArts 数据治理** 搭配（集成后的数据入治理中心）。
