# CSE 微服务引擎（Cloud Service Engine）

## 一、产品定位
CSE 是华为云基于 Apache ServiceComb 开源框架构建的微服务基础设施平台，为微服务提供"注册发现、配置管理、服务治理、分布式事务"等核心能力。它让企业无需从零搭建微服务中间件，即可快速构建、治理云原生微服务应用。兼容 Spring Cloud / Dubbo / Go / Service Mesh 主流生态，是微服务架构的"底座脚手架"。

## 二、核心能力
1. **服务注册与发现**：兼容 Nacos / Eureka，服务实例自动注册、自动剔除。
2. **分布式配置中心**：配置集中管理、动态下发，无需重启生效。
3. **限流熔断与降级**：集成 Sentinel，保护服务不被雪崩。
4. **分布式事务（Seata）**：保障跨服务数据一致性。
5. **服务网格（Service Mesh）**：支持 Sidecar 模式渐进式演进到 Mesh。
6. **多语言 SDK**：Java / Go / Python / Dubbo，异构微服务统一管理。
7. **灰度发布与蓝绿部署**：按版本 / 权重路由流量。
8. **全链路追踪与监控**：调用链可视化，定位慢调用。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：Spring Cloud 微服务迁移上云**
  - 痛点：自建注册中心 / 配置中心运维重、无治理。
  - 方案：微服务迁移到 CSE，复用 Spring Cloud 注解，零改造接入。
  - 价值：免运维注册/配置中心，获得限流、事务、追踪能力。
- **场景2：Dubbo 传统微服务升级**
  - 痛点：老 Dubbo 系统治理手段弱。
  - 方案：接入 CSE 治理中心，获得熔断、灰度能力。
- **场景3：多语言异构微服务治理**
  - 痛点：Java / Go 服务混布，治理不统一。
  - 方案：CSE 多语言 SDK 统一治理。

## 四、常见搭配
- 与 **CCE 云容器引擎** 原生集成（K8s 上跑微服务，CSE 做治理）。
- 与 **APIG API 网关** 搭配（APIG 做南北向入口，CSE 做东西向服务治理）。
- 与 **ServiceStage 应用管理** 搭配（部署 + 治理一体化）。
- 与 **LTS / CES** 搭配（调用链日志与监控）。
