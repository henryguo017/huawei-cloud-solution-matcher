# LTS 日志服务（Log Tank Service）

## 一、产品定位
LTS 是华为云提供的日志采集、存储、检索与分析服务，是云上可观测体系的"日志层"。它支持主机日志（ICAgent）、云服务日志、API 直传三种接入方式，提供全文检索、SQL 分析、可视化图表与告警，帮助企业实现日志统一管理、故障排查、安全审计与价值挖掘。相比自建 ELK，LTS 免运维、成本低、开箱即用。

## 二、核心能力
1. **ICAgent 主机日志采集**：自动采集 ECS / 容器日志，免配置。
2. **云服务日志一键接入**：CES / WAF / HSS 等日志直接入 LTS。
3. **API / SDK 直传日志**：业务自定义日志上报。
4. **全文检索与 SQL 分析**：亿级日志秒级检索，SQL 毫秒返回。
5. **日志结构化提取**：非结构化日志转字段，便于分析。
6. **可视化仪表盘**：日志图表化，趋势直观。
7. **日志转储 OBS 长期保存**：冷热分层，合规留存。
8. **日志告警规则**：异常日志实时告警。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：应用日志集中管理与分析**
  - 痛点：日志散落各台机器，排查靠登机器 grep。
  - 方案：ICAgent 采集日志统一入 LTS，全文检索。
  - 价值：故障定位从小时级降到分钟级。
- **场景2：访问日志与安全审计**
  - 痛点：等保要求日志留存与审计。
  - 方案：访问 / 操作日志入 LTS，转储 OBS 长期留存。
- **场景3：错误日志实时告警**
  - 痛点：线上报错无人知。
  - 方案：LTS 告警规则，错误日志触发 SMN 通知。

## 四、常见搭配
- 与 **ECS / CCE** 搭配（采集主机 / 容器日志）。
- 与 **CES 云监控** 搭配（指标 + 日志联合排障）。
- 与 **SMN 消息通知** 搭配（日志告警推送）。
- 与 **OBS** 搭配（日志冷存储长期留存）。

## 五、公开参考价（华北-北京四，2026 口径，⚠部分待官网复核）
- 标准存储（按量）：约 **¥0.47/GB·月**（索引 + 存储）。
- 冷存储更低；ICAgent 采集免费。
- 计费模式：按日志写入量 / 存储量按量付费。

## 六、售前话术要点
- 客户问"日志怎么管"——答：LTS，采集→存储→检索→分析→告警一站式，比自建 ELK 省 50% 成本。
- 强调高性能：亿级日志秒级检索，SQL 毫秒返回。
- 强调合规：日志转储 OBS 长期留存，满足等保审计。
