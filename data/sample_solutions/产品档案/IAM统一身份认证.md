# IAM 统一身份认证（Identity and Access Management）

## 一、产品定位
IAM 是华为云统一的身份与权限管理服务，相当于云上所有资源的"门禁系统 + 权限管理后台"。它管理谁能登录、能操作哪些资源、能做什么操作，是云上安全治理的第一道关。支持基于策略的细粒度权限（RBAC）、多因素认证（MFA）、单点登录（SSO）和企业身份联邦，覆盖所有华为云服务，是企业上云后做"身份治理"的必选基础服务。

## 二、核心能力
1. **用户 / 用户组管理**：创建子用户、按团队分组，避免共用主账号。
2. **基于策略的权限控制（RBAC）**：资源级 + 操作级精确授权，最小权限原则。
3. **多因素认证（MFA）**：TOTP / U2F 硬件密钥，登录二次验证。
4. **SSO 单点登录**：支持 SAML / OIDC，企业员工一次登录访问所有云资源。
5. **LDAP / AD 身份联邦**：对接企业现有 AD / LDAP，免重复建账号。
6. **委托临时安全凭证**：跨账号 / 跨服务临时授权，避免长期 AKSK 泄露。
7. **访问密钥（AK/SK）管理**：给程序调用用的密钥，支持轮换。
8. **审计日志**：所有 IAM 操作留痕，满足等保合规。

## 三、适用场景（痛点 → 方案 → 价值）
- **场景1：企业员工云资源权限管控**
  - 痛点：多人共用主账号，权限混乱、离职不清权限。
  - 方案：建 IAM 子用户 + 用户组，按岗位授权。
  - 价值：权限清晰、离职即禁用、操作可审计。
- **场景2：SSO 统一登录控制台**
  - 痛点：员工需在多个系统分别登录。
  - 方案：IAM 对接企业 IdP 做 SSO。
- **场景3：等保合规身份审计**
  - 痛点：等保要求身份审计与最小权限。
  - 方案：IAM 策略 + MFA + 审计日志满足合规。

## 四、常见搭配
- 与 **HSS 主机安全 / WAF** 搭配（IAM 管人，安全服务管资源防护，联动权限收敛）。
- 与 **APIG / DEW** 搭配（APIG 鉴权委托 IAM，DEW 加密凭据）。
- 与 **APIG API 网关** 搭配（APIG 把请求交给 IAM 做统一鉴权）。
- 几乎所有华为云服务都依赖 IAM 做权限底座。

## 五、公开参考价（华北-北京四，2026 口径，已核验）
- **IAM 基础功能免费**：用户 / 用户组 / 策略 / 权限管理免费。
- MFA 硬件令牌等高级物理凭证可能单独收费。
- 计费模式：基础身份治理免费，是云上"标配免费底座"。

## 六、售前话术要点
- 客户问"怎么管云上权限"——答：IAM，所有云资源的统一门禁，按岗位授权、支持 SSO、MFA、审计。
- 强调合规：细粒度权限 + MFA + 审计日志，等保身份安全基线直接满足。
- 强调免费：基础身份管理是免费的，企业治理零门槛起步。
