# AWS智能制造解决方案

## 公司概况
AWS 将工业制造列为重点行业，以 AWS IoT 与机器学习为核心，提供设备联网到数字孪生与生成式AI的云端能力，并通过 APN 整合西门子、德勤等工业伙伴。

## 智能制造核心方案

### 1. 工业物联网与数据采集
- AWS IoT Core 提供设备与云安全双向通信（MQTT/HTTPS）。
- AWS IoT SiteWise 采集、组织、监控工业设备数据，对接 PLC/SCADA/Historian，自动计算 OEE；SiteWise Edge 边缘预处理，三级存储降本；SiteWise Monitor 免代码生成看板。

### 2. 预测性维护与质检
- Amazon Lookout for Equipment 用历史数据训练模型，自动检测异常并定位根因，实现预测性维护，可与 SiteWise 同步。
- AWS Panorama 边缘运行计算机视觉，用于产线质检、缺陷识别与 PPE 安全检测。
- Amazon SageMaker 构建质检与工艺优化模型。

### 3. 数字孪生与智能工厂
- AWS IoT TwinMaker 创建工厂/产线/设备数字孪生，融合传感器与企业数据，提供 3D 可视化与孪生图谱，支持与 SiteWise 资产自动同步，可在 Managed Grafana 或 React 呈现。

### 4. 生成式AI与生态
- Amazon Bedrock 支撑文档抽取与工艺辅助；西门子、德勤在 AWS 交付 OT-IT 融合方案。

## 竞争优势
- IoT 与 AI/ML 广度领先，SiteWise/TwinMaker/Lookout/Panorama 形成端云闭环；伙伴生态成熟；弹性按量计费，适合多厂区。

## 主要客户案例（仅可核实）
- 公开资料显示西门子、德勤等在 AWS 交付智能制造方案，终端量化成效以官网为准；属“典型行业实践”，无确凿可核实的中国大型制造企业命名案例，不编造公司名与数据。

## 核心劣势（中国市场）
- OT 与端侧硬件空白：不生产 PLC/工控机/传感器，依赖西门子，缺华为云“云边端”一体硬件。
- 中国大陆无本地公有云直接运营（北京光环新网、宁夏西云数据），工业数据出境受限，难满足数据驻留。
- 信创合规弱：不支持国产 CPU/OS/数据库替换，难进关键制造国企。
- 方案多为通用 PaaS，缺本土化行业套件与本地实施体系。
