# AWS智能汽车解决方案

## 公司概况
AWS 围绕“新四化”（电动化、网联化、智能化、共享化）提供车联网、自动驾驶、软件定义汽车、数字化营销与供应链完整云端方案，依托 APN 伙伴网络加速车企出海，中国区方案遵循数据驻留要求。

## 智能汽车核心方案

### 1. 车联网与数据采集
- Guidance for Connected Mobility on AWS 提供模块化网联出行参考架构，实现云边端协同的数据传输、处理、分析。
- AWS IoT FleetWise（官方已停止接受新客户，存量可继续用）标准化采集转换车辆数据，统一传感器与视觉数据，支撑车队健康与 ML 训练。
- BlackBerry IVY 为云连接车载软件平台，统一安全读取标准化车辆传感器数据，车端与云端生成洞察。

### 2. 自动驾驶与数据湖
- 自动驾驶数据湖端到端覆盖采集、编目、标注、检索、可视化，中国区增强版新增 3D 点云标注与车道线检测训练；EC2/S3/FSx for Lustre/Batch 支撑仿真训练。

### 3. 软件定义汽车
- 云原生支撑整车 OTA、车云对等环境与持续软件交付，缩短功能上车周期并保留功能安全。

### 4. 数字化营销与供应链
- Customer 360/CDP 结合 Personalize 实现个性化营销；Amazon Connect 支撑智能呼叫中心；供应链控制塔、可追溯性、需求预测覆盖制造到维护全生命周期。

## 竞争优势
- 车联网、自动驾驶、软件定义汽车全栈云能力齐全，全球基础设施具车企出海优势；AI/ML 与数据湖深厚；伙伴生态广。

## 主要客户案例（仅可核实）
- 丰田互联（中国）大数据车联网平台基于 AWS，实现运维自动化（AWS 公开案例）。
- 上汽海外智能网联系统采用 AWS 整体方案；WirelessCar（中国）基于 AWS 无服务器架构构建弹性车联网平台（AWS 公开案例）。
- 大众（Volkswagen）、宝马（BMW）为 AWS 全球汽车客户，属可核实行业实践。

## 核心劣势（中国市场）
- 关键车联网服务 IoT FleetWise 已停收新客户，新项目需按 Connected Mobility 指南自建，增加集成运维成本。
- 中国大陆无本地公有云直接运营，依赖光环新网/西云数据，车辆数据出境受《数据安全法》《个人信息保护法》限制，需额外合规架构。
- 缺乏端侧/车规硬件布局，云下能力依赖第三方，不如华为“车云一体+硬件”闭环。
- 信创适配弱，难满足部分国有车企国产技术栈要求；国内汽车云市场面临华为云、阿里云强力竞争。
