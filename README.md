## 🧩 核心功能（全模块一览）

### 1. 三种匹配模式
- **标准模式**：输入需求文本 → 向量检索 → LLM 生成结构化方案（14 章固定结构，质量稳定）。**免登录可用**。
- **Agent 模式（智能 · Agentic Workflow）**：自写编排引擎驱动「需求分析 → 检索知识库 → 检索竞品 → 生成方案」循环，SSE 实时推送 AI 的**思考流**，能看到它一步步怎么推理。**需登录**（记忆与画像依赖账号）。
- **向导模式**：行业 → 规模 → 痛点 → 确认，4 步引导自动合成需求后提交匹配，不会写需求也能出方案。**免登录可用**。

### 2. 客户档案与 Agent 记忆隔离（仅 Agent 模式）
- Agent 模式下显示「当前客户档案」栏，下拉选择客户（或「+ 新建」「× 删除」），记忆键为 `用户ID:客户ID`，**同一销售的不同客户记忆完全隔离**。
- 选择「（全局记忆 · 不限定客户）」时退化为账号级共享记忆。
- 跨用户隔离由 JWT 绑定的 `user_id` + 客户表外键双重保证，A 客户的资料不会出现在 B 的列表、也读不到 A 的记忆。

### 3. Agent 持久记忆与用户画像（仅 Agent 模式）
- **跨对话记忆**：同一客户的多次匹配共享上下文，最近 15 轮进入窗口，超过 30 天自动归档（不删除），下次可溯源。
- **用户画像**：Agent 自动从对话中提炼销售风格 / 惯用打法，沉淀为「用户画像」（按账号维度，独立于客户记忆），越用越懂你。

### 4. 用户独立知识库
- 每个用户拥有**完全隔离**的知识库（文件 + ChromaDB 向量库），注册自动从默认库复制。
- 支持在线**增删改文档**，改动后一键**单文件重索引**。
- 知识库内置约 170 篇方案资料：**华为云约 50 篇**（覆盖 17 个行业，如智慧城市 / 智慧园区 / 工业互联网 / 金融 / 医疗 / 制造 / 政务 / 零售 / 游戏 / 汽车 / 生物医药等）+ **12 家竞品厂商共 120 篇**，全部切分为约 276 个向量片段用于检索，覆盖 **10 大核心行业**（华为云行业体系共 17 个）。

### 5. 竞品分析
- 内置 12 家主流厂商（阿里云 / 腾讯云 / AWS / 微软 Azure / Google Cloud / Oracle Cloud / 天翼云 / 移动云 / 联通云 / 字节跳动火山引擎 / 西门子 / 施耐德电气）方案对比资料。
- 选择「竞品 + 行业」即可生成与华为云方案的客观对比、差异化优势与销售应对话术。**免登录可用**。

### 6. 客户资料上传 + OCR（阶段一）
- 在 Agent 模式下可上传客户资料文件，支持 .txt / .docx / .pdf / .png / .jpg。
- 图片自动调用 OCR（生产环境已装 `tesseract-ocr` + `chi_sim` 中文包）识别文字后纳入上下文；路径经白名单校验，杜绝越权读取。
- 单文件上限 100MB，扩展名白名单过滤。

### 7. 方案导出
- 匹配 / 竞品分析结果可一键生成 **Word 报告**（含方案正文 + 来源文档 + 元数据），直接发给客户或二次编辑。**免登录可用**。

### 8. 历史方案（四块增强）
- **下载**：导出 Word 文档，列表显示「已下载」徽标。
- **归档 / 取消归档**：长期沉淀优质方案，列表显示「已归档」徽标。
- **方案追问优化**：基于已有方案继续让 AI 精修（如"价格部分再详细一点"），保留追问历史。
- **详情查看**：回看完整方案与来源文档。

### 9. 账号与鉴权
- **账号注册（用户名 / 邮箱，带验证码）+ JWT 会话管理**；支持邮箱找回密码。
- **登录闸分层**：仅 Agent 模式强制登录，其余引擎免登录即可用。

### 10. 成就系统
- 基于使用行为解锁成就徽章，把"用工具"变成有点游戏感的事。

### 11. 数据看板
- 直观展示知识库文档数、行业覆盖数、行业分布图，一眼看清"家底"。

### 12. 产品图谱
- 可视化浏览华为云产品体系，作为方案设计的参考视图。

### 13. 内置 AI 问答助手（顶部面板）
点顶栏 AI 按钮即可打开，内置三层智能路由，能回答三类问题：

1. **平台使用类**（「怎么用」「有什么区别」「如何导出/对比/定稿/回滚」等）→ **使用向导**：基于内置的《平台功能完整说明》给出准确、具体的操作指引，覆盖全部功能模块与入口，不编造。
2. **云计算 / 华为云 / 竞品业务类**（如「华为云数据库有哪些」「金融上云架构怎么选」）→ **对话式 RAG**：先检索你的知识库资料，再基于资料给出专业回答。
3. **其他话题** → **通用闲聊**：像朋友一样自然交流。

面板内提供 8 张**快捷提问卡片**（业务类 + 平台使用类），点一下即可发送；关闭面板会清空当前对话，下次打开是新会话。身份锚定为「cloudsol.cn 内置 AI 助手，由本项目原创开发，不属于任何第三方大模型厂商」。

## 🎮 趣味性玩法（试试这些）

- **看 AI 现场「思考」**：用 Agent 模式，右侧会实时滚出 AI 的思考流——它先分析你要什么、再去翻哪份资料、怎么综合，像看一位顾问在你面前工作。
- **分客户记记忆**：在 Agent 模式里给客户 A、客户 B 各建档案，分别匹配后系统各自记得背景，下次接着聊不串味。
- **竞品 PK 擂台**：在竞品分析里输入友商名字，看系统怎么把华为云和它逐项对比，客户问"你和 XX 比咋样"时直接有底气。
- **打造你的私人方案库**：往自己的知识库里塞行业案例、老方案、竞品笔记，系统会变成"只属于你"的方案大脑。
- **成就解锁收集**：多用多解锁，看徽章墙一点点亮起来。
- **换肤看心情**：4 套配色随手切，经典蓝开会、桃桃粉摸鱼（不是）。
- **向导零门槛**：完全不会描述需求？点向导，像填表一样把客户情况点出来，方案自动生成。
- **手机随身演示**：掏出手机打开网页就能给客户现场出方案，不用背电脑。

## 🚀 本地运行

```bash
# 1. 克隆
git clone https://github.com/henryguo017/huawei-cloud-solution-matcher.git
cd huawei-cloud-solution-matcher

# 2. 创建虚拟环境并安装依赖（国内建议加镜像）
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

# 3. 配置环境变量
cp .env.example .env   # 按需填写大模型 API Key 等

# 4. 初始化数据库（幂等，可重复执行）
python -m app.utils.db_init

# 5. 启动后端（开发模式带热重载）
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

浏览器访问 `http://127.0.0.1:8000` 即可。

> 启用 OCR 需在系统中安装 `tesseract-ocr` 与中文包：`apt-get install -y tesseract-ocr tesseract-ocr-chi-sim`，并在 venv 中 `pip install pytesseract Pillow`。

## 🐛 已知修复记录

- **收藏 / 历史接口 404**：`auth_routes.py` 子路由原为 `@router.get("/")` 注册路径带尾部斜杠，而前端调用无斜杠，FastAPI 子路由嵌套时不自动重定向 → 已改为 `@router.get("")` 匹配无斜杠请求。
- **Agent 记忆跨客户串味**：原 `session_id = 用户ID` 导致同账号所有客户共用一条记忆线 → 引入客户档案，`session_id = 用户ID:客户ID` 按客户隔离。
- **匿名共享记忆池风险**：原 Agent 模式允许匿名使用导致 `user_id=0` 共享池 → 改为 `require_login` 强制登录，彻底消灭共享池。
- **移动端过度滚动留白**：JS 精确像素硬锁 `main-content` 高度，根治空白。
- **AI 身份暴露**：闲聊 prompt 加身份锚点，避免被误认为第三方大模型。
- **AI 助手快捷卡片消失（v2026-07-18）**：`close()` 未恢复发消息时被隐藏的快捷建议区，导致关闭再打开变空白 → 已恢复显示并重置思考状态。
