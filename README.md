## ✨ 本次更新重点：大换肤 + 操作界面优化

本次版本对整体视觉与操作体验做了一次完整重构，核心变化如下：

### 1. 主题皮肤系统升级为 4 色

侧边栏 + 顶栏支持一键换肤，用户可在「设置」中自由切换，偏好持久化保存：

| 皮肤 | 标识 | 侧栏 / 顶栏配色 | 风格 |

| 经典蓝 | `classic-blue` | `#1B4F72` / `#154360` | 沉稳专业，默认皮肤 |

皮肤通过 `data-skin` 属性联动 CSS 变量（`--sidebar-bg` / `--topbar-bg` / `--frame-text`），所有框架内文字强制纯白，保证对比度与可读性。

### 2. 视觉语言整体刷新

- **品牌色**：统一为华为红 `#C7000B`（仅作强调，去除发光/光晕效果，界面更克制专业）
- **底色体系**：页面冷灰底 `#E8EAED` + 毛玻璃卡片（极浅米白→纯白渐变），层级清晰
- **文字层级**：主文字深墨 `#1A1C23`、副文字灰蓝 `#4A5067`、弱文字 `#8890A4`，三级层次分明
- **圆角与阴影**：统一圆角 + 轻量阴影（`0 4px 16px rgba(0,0,0,.06)`），去除 Heavy 阴影带来的廉价感
- **字体**：系统无衬线字体栈，移动端输入框/可点击元素最小 16px，避免 iOS 聚焦缩放

### 3. PC 端操作界面优化

- 左侧固定**侧边导航栏**：方案匹配 / 竞品分析 / 产品图谱 / 数据仪表盘 / 历史记录 / 成就中心 / 知识库 / 设置，图标 + 文字双标识，激活态高亮
- 顶栏与侧栏底色随皮肤联动，常驻用户状态与主题切换入口
- 全局表格支持横向滚动，长内容区不再撑破布局

### 4. 移动端专项重构（响应式）

手机端（≤767px）完全独立设计，不再只是 PC 端的缩放：

- **5 Tab 底部导航**：匹配 · 竞品 · 仪表盘 · 知识库 · 我的，固定底部 56px，拇指可达
- **「我的」聚合页**：用户信息 / 收藏 / 历史 / 成就 / 设置入口聚合，底部统计信息（文档数 · 行业数 · 版本号）自动沉底
- **子页独立返回导航条**：历史 / 成就 / 设置进入后顶部带返回键（独立 nav 条，非 header 内嵌），一键返回「我的」
- **抽屉化交互**：弹窗 / 详情改为底部滑入抽屉，符合移动端习惯
- **卡片布局**：成就卡片一行 3 列紧凑展示；设置项间距收窄，操作更密集高效
- **页面切换动效**：复制 PC 端「淡淡上滑」体验（`translateY(4px)` / 0.18s），不再生硬弹出
- **消除移动端留白**：精确像素硬锁内容区高度，根治过度滚动产生的空白

## 🧩 核心功能（全模块一览）

### 1. 三种匹配模式
- **标准模式**：输入需求文本 → 向量检索 → LLM 生成结构化方案（14 章固定结构，质量稳定）
- **智能模式（Agentic Workflow）**：自写编排引擎驱动「需求分析 → 检索知识库 → 检索竞品 → 生成方案」循环，SSE 实时推送 AI 的**思考流**，能看到它一步步怎么推理
- **向导模式**：行业 → 规模 → 痛点 → 确认，4 步引导自动合成需求后提交匹配，不会写需求也能出方案

### 2. 用户独立知识库
- 每个用户拥有**完全隔离**的知识库（文件 + ChromaDB 向量库），注册自动从默认库复制
- 支持在线**增删改文档**，改动后一键**单文件重索引**
- 知识库内容：华为云方案文档 + 主流竞品分析文档，覆盖 17 个行业

### 3. 竞品分析
- 内置 12 家主流厂商（阿里云 / 腾讯云 / AWS / Azure / 天翼云 / 火山引擎等）方案对比资料
- 输入竞品名称即可生成与华为云方案的客观对比，帮销售在客户面前做差异化论证

### 4. 方案导出
- 匹配结果可一键生成 **Word 报告**（含方案正文 + 来源文档 + 元数据），直接发给客户或二次编辑

### 5. 账号与资产
- 手机号注册 / 登录（带验证码），JWT 会话管理
- 登录后可**收藏**方案、**查看历史记录**，跨设备接着用

### 6. 成就系统
- 基于使用行为解锁成就徽章，把"用工具"变成有点游戏感的事

### 7. 数据看板
- 直观展示知识库文档数、行业覆盖数、行业分布图，一眼看清"家底"

### 8. 产品图谱
- 可视化浏览华为云产品体系，作为方案设计的参考视图

### 9. 内置 AI 助手
- 闲聊与答疑，身份锚定为「cloudsol.cn 内置 AI 助手，由本项目原创开发，不属于任何第三方大模型厂商」

## 🎮 趣味性玩法（试试这些）

- **看 AI 现场「思考」**：用智能模式，右侧会实时滚出 AI 的思考流——它先分析你要什么、再去翻哪份资料、怎么综合，像看一位顾问在你面前工作。
- **竞品 PK 擂台**：在竞品分析里输入友商名字，看系统怎么把华为云和它逐项对比，客户问"你和 XX 比咋样"时直接有底气。
- **打造你的私人方案库**：往自己的知识库里塞行业案例、老方案、竞品笔记，系统会变成"只属于你"的方案大脑。
- **成就解锁收集**：多用多解锁，看徽章墙一点点亮起来。
- **换肤看心情**：4 套配色随手切，经典蓝开会、桃桃粉摸鱼（不是）。
- **向导零门槛**：完全不会描述需求？点向导，像填表一样把客户情况点出来，方案自动生成。
- **手机随身演示**：掏出手机打开网页就能给客户现场出方案，不用背电脑。

## 🚀 本地运行

```bash
# 1. 克隆
git clone https://github.com/henryguo017/huawei-cloud-solution-matcher.git
cd huawei-cloud-solution-matcher

# 2. 创建虚拟环境并安装依赖（国内建议加镜像）
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

# 3. 配置环境变量
cp .env.example .env   # 按需填写大模型 API Key 等

# 4. 初始化数据库
python -m app.utils.db_init

# 5. 启动后端（开发模式带热重载）
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

浏览器访问 `http://127.0.0.1:8000` 即可。

## 🐛 已知修复记录

- **收藏 / 历史接口 404**：`auth_routes.py` 子路由原为 `@router.get("/")` 注册路径带尾部斜杠，而前端调用无斜杠，FastAPI 子路由嵌套时不自动重定向 → 已改为 `@router.get("")` 匹配无斜杠请求。
- **移动端过度滚动留白**：JS 精确像素硬锁 `main-content` 高度，根治空白。
- **AI 身份暴露**：闲聊 prompt 加身份锚点，避免被误认为第三方大模型。
