## 一、本批实现的功能

### 1. 对话草稿（按对话隔离）
- 输入框打字防抖 300ms 自动落盘（localStorage），**每个对话独立槽位**，切走再切回自动恢复。
- 发送成功即删草稿；清空输入 = 删除草稿；对话删除时草稿一并删除；LRU 上限淘汰最旧草稿。
- **点能力 / 点快捷场景填入的模板同样落草稿**（此前程序赋值不触发 input 事件导致模板切走即丢——本轮实测暴露并修复）。
- 侧栏任务项显示红色「**草稿**」徽标（有未发送输入时），清空或发送后消失。
- 欢迎页（新对话）不存草稿、新建对话清空输入框（产品拍板）。

### 2. 图片输入理解（识图全链路）
- **上传入口**：文件选择 + Ctrl+V 直接粘贴截图，输入框上方出现图片 chip（可删除）。
- **安全校验**（服务端）：相对路径白名单校验、拒绝绝对路径/`..` 越界、扩展名白名单、单张 ≤10MB。
- **Vision 预处理**：DeepSeek 视觉模型将图片转文字描述（生产日志实测 `prompt_tokens=231, completion_tokens=96`），描述注入 Agent 上下文。
- **Agent 消费**：两阶段编排自动生成含"解析图片"的执行计划，最终回答**基于图片真实内容**（测试图含 ERP/MES/OA 系统架构，Agent 终稿准确列出系统清单并衔接上云迁移方案）。
- **历史还原**：用户气泡保留缩略图；重新打开历史对话显示图片徽标（SVG，非 emoji）。

### 3. 能力胶囊交互修正
- 点击能力 → 模板填入输入框（同时落草稿），**菜单项不再常亮**（含历史对话恢复时不点亮）。

### 4. 自动化任务（通用自定义）
- 订阅页签自定义创建任务 → 列表展示 → **run-now 真实执行**（返回 `{"ok":true,"summary":"链路正常"}`，实测 elapsed 12.5s/24s）→ 删除。

## 三、测试过程中发现并修复的缺陷（全部带根因）

| 缺陷 | 根因 | 修复 commit |
|---|---|---|
| Agent 视图初始化崩、侧栏不渲染 | 粘贴监听写在 `_bind` 靠前处却引用了后面才声明的 `input` 局部变量 → ReferenceError 中断初始化 | `f952290` |
| 订阅页签 run-now 被限流误杀 | `rate_limit` 桶 key 只有 IP 没有路由路径，同 IP 所有端点共享同桶 | `9767e9b` |
| 图片问答 404 | upload 返回的相对路径已含 `customer_uploads/` 前缀，校验函数又拼了一层（双重路径） | `c4df809`（含路径解析单测：正常/越界/后缀/缺失四类） |
| 切回历史对话能力胶囊常亮 | `_openConvo` 按 `cap` 字段恢复点亮（该字段只是 UI 记账，不参与提示词） | `5d92971` |
| **点能力填的模板切走即丢** | 程序赋值不触发 `input` 事件 → 草稿从未落盘 | `7f60589` |

## 四、测试方法说明与遗留事项

1. **Agent 答案等待策略**：两阶段执行期间 DOM 可 40s+ 无变化，E2E 采用「关键词命中 OR 文本稳定 120s」双条件取终稿——单纯"文本变长即返回"会误抓执行计划中间态（本次 T3 首轮 FAIL 即此因，非功能缺陷）。
2. **限流测试约束**：限流修复（key 含路由路径）已部署，E2E 仍保留 run-now 前 65s 等待以完全隔离相邻请求，验证的是产品逻辑而非限流本身。
3. **健康检查口径**：ECS 内网 `curl 127.0.0.1:8000` 返回 000 与内部监听端口有关，外网走 nginx 正常——统一以 `https://cloudsol.cn/api/knowledge/stats` 为准（重启后 KB 902 片段加载约 40s 内 502 属预热，非故障）。
4. **识图能力边界**：Vision 预处理单张 ≤10MB；描述由视觉模型生成后注入文字链路，Agent 不直接消费原始像素，超清大图细节可能损失。
