> 方式 B（手动，等价步骤，在服务器 root 下执行）：
```bash
cd /tmp
rm -rf huawei-cloud-solution-matcher huawei-cloud-solution-matcher-main hcsm_main.zip
wget "https://github.com/henryguo017/huawei-cloud-solution-matcher/archive/refs/heads/main.zip" -O hcsm_main.zip
python3 -c "import zipfile; zipfile.ZipFile('hcsm_main.zip').extractall('/tmp')"
rsync -a --exclude='data' --exclude='.git' /tmp/huawei-cloud-solution-matcher-main/ /var/www/huawei-cloud-solution-matcher/
systemctl restart huawei-cloud-api
sleep 2
systemctl status huawei-cloud-api --no-pager | head -6
journalctl -u huawei-cloud-api -n 10 --no-pager
```

> ⚠️ 若 `wget` 因 GitHub 网络不稳失败：重跑一次 wget 即可。
> ⚠️ 若重启后服务起不来（journalctl 报 `ModuleNotFoundError`）：补装依赖
> ```bash
> cd /var/www/huawei-cloud-solution-matcher
> pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
> systemctl restart huawei-cloud-api
> ```

## 第四步：配置服务器 `.env`（SMTP + JWT）
> 部署不会改 `.env`，需手动确保以下两项到位。

**4.1 SMTP 授权码**（用聊天记录中给你的 sed 命令，含新授权码，兼容"有则替换/无则追加"）：
```bash
cd /var/www/huawei-cloud-solution-matcher
grep -q '^SMTP_PASS=' .env && sed -i "s|^SMTP_PASS=.*|SMTP_PASS=<聊天里的新授权码>|" .env || echo 'SMTP_PASS=<聊天里的新授权码>' >> .env
```

**4.2 JWT 随机强密钥**（自动生成，不落明文）：
```bash
cd /var/www/huawei-cloud-solution-matcher
NEW_JWT=$(openssl rand -hex 32)
grep -q '^JWT_SECRET_KEY=' .env && sed -i "s|^JWT_SECRET_KEY=.*|JWT_SECRET_KEY=$NEW_JWT|" .env || echo "JWT_SECRET_KEY=$NEW_JWT" >> .env
```
