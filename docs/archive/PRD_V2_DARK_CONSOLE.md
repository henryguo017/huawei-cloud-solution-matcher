# 华为云方案匹配系统 — 全站视觉重设计 PRD v2.0（深色控制台版）

> 文档状态：**待用户确认后开发**
> 核心问题：v1.0 实施后内容区仍为纯白/近白，整体观感像"半成品模板"，缺乏企业控制台的质感与深度
> 设计方向：**深色导航框架 + 冷灰内容底 + 半透明毛玻璃卡片 + 华为红品牌色 + 动效层次**

---

## 1. 问题诊断

### 1.1 当前痛点（来自用户真实反馈）

| 痛点 | 具体表现 | 用户原话 |
|------|---------|---------|
| **太白** | 内容区 `#F0F2F5` + 卡片 `#FFFFFF` = 几乎全白，无层次 | "整个页面太多白色了，很丑" |
| **没特点** | 跟任何 Bootstrap 模板无法区分 | "没有特点" |
| **不像大厂** | 真正的企业控制台没有一个用纯白 | "谁家是全白色的" |
| **品牌弱** | 只有侧边栏有红色，内容区完全丢失品牌感 | — |
| **缺动效** | 静态白卡，无过渡动画、无微交互 | "特效动感最好还是有" |

### 1.2 对标分析：主流云控制台的内容区配色

| 控制台 | 导航栏背景 | **内容区背景** | 卡片颜色 | 特点 |
|--------|-----------|--------------|---------|------|
| **华为云控制台** | `#1b1f2d` 深蓝黑 | **`#f5f6fa` 冷灰蓝** | `#fff` + 重阴影 | 页面顶部有品牌色渐变条 |
| **阿里云控制台** | `#23263a` 深灰蓝 | **`#f3f4f6` 中性冷灰** | `#fff` + 细边框 | 卡片之间间距大，呼吸感强 |
| **腾讯云控制台** | `#1e1e2d` 近黑 | **`#f7f8fa` 极浅灰** | `#fff` 微圆角 | 蓝色品牌点缀 |
| **AWS Console** | `#16191f` 黑色 | **`#fafafa` 近白但非纯白** | `#fff` 无边框 | 极简风，靠信息密度 |
| **Vercel Dashboard** | `#000` 纯黑 | **`#0a0a0a` 深黑** | **`#111` 深卡片** | 新一代风格：全局深色+高对比文字 |

### 1.3 结论

当前系统用的是类似 AWS 的「近白」方案，但缺少：
1. ❌ **内容区不够暗** —— `#F0F2F5` 在显示器上看起来就是白色
2. ❌ **卡片是纯白 `#FFFFFF`** —— 在浅底上对比度极低
3. ❌ **没有任何视觉深度** —— 无阴影层次、无渐变、无动画
4. ❌ **品牌色只在侧边栏** —— 内容区完全脱离品牌

## 2. 设计方向：「冷灰深空」控制台

### 2.1 核心理念

> **不是把页面变黑，而是让每个像素都有存在的意义。**
> 
> 通过「四级灰阶体系」+「毛玻璃卡片」+「品牌光晕」，在保持可读性的前提下建立视觉深度。

### 2.2 四级灰阶体系

```
┌─────────────────────────────────────────────┐
│  L0: 深色框架 (已实现)                       │  #14162B  侧边栏 + 顶栏
│  ┌───────────────────────────────────────┐   │
│  │  L1: 内容底色 (本次核心改动)           │   │  #E8EAED  ← 从 #F0F2F5 加深
│  │  ┌─────────────────────────────────┐ │   │
│  │  │  L2: 卡片表面 (毛玻璃)          │ │   │  rgba(255,255,255,0.72) + blur
│  │  │  ┌───────────────────────────┐  │ │   │
│  │  │  │  L3: 输入框/内嵌组件      │  │ │   │  #FFFFFF (纯白仅用于输入区域)
│  │  │  └───────────────────────────┘  │ │   │
│  │  └─────────────────────────────────┘ │   │
│  └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘

品牌色 #C7000B 贯穿所有层级：激活态、按钮、关键数据、光晕装饰
```

### 2.3 新设计 Token 定义

```css
/* === L1: 内容区底色（从纯白改为冷灰）=== */
--bg-page:        #E8EAED;      /* 原 #F0F2F5，加深20% */
--bg-page-alt:    #DEE1E6;      /* 交替行/分区背景 */

/* === L2: 卡片表面（毛玻璃效果）=== */
--bg-card:        rgba(255, 255, 255, 0.72);   /* 原纯白 #FFF */
--card-border:    rgba(255, 255, 255, 0.45);
--card-shadow:    0 4px 24px rgba(0, 0, 0, 0.06), 
                  0 1px 3px rgba(0, 0, 0, 0.04);
--card-radius:    14px;
--card-hover-shadow: 0 8px 32px rgba(0, 0, 0, 0.10),
                    0 2px 8px rgba(199, 0, 11, 0.06);

/* === L3: 输入区域（唯一允许纯白的地方）=== */
--bg-input:       #FFFFFF;
--input-border:   #D1D5DB;
--input-focus-border: #C7000B;
--input-focus-glow: 0 0 0 3px rgba(199, 0, 11, 0.12);

/* === 文字层级（适配新背景）=== */
--text-primary:   #1A1C23;     /* 主文字 - 深墨色 */
--text-secondary: #4A5067;     /* 副文字 - 灰蓝 */
--text-muted:     #8890A4;     /* 弱文字 - 浅灰蓝 */
--text-on-dark:   #E5E7EB;     /* 深色面上的文字 */

/* === 品牌光晕（新增）=== */
--brand-glow:     0 0 20px rgba(199, 0, 11, 0.15);
--brand-glow-strong: 0 0 30px rgba(199, 0, 11, 0.25);

/* === 动效（保留原有 + 增强）=== */
--transition-smooth: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);

/* === 渐变装饰 === */
--page-header-gradient: linear-gradient(135deg, #C7000B 0%, #E02020 50%, #FF6A3D 100%);
--card-accent-gradient: linear-gradient(180deg, rgba(199,0,11,0.03) 0%, transparent 100%);
```

## 3. 逐页视觉规范

### 3.1 方案匹配页（#page-solution）

**目标**：作为用户第一眼看到的页面，必须有冲击力。

| 区域 | v1.0（当前） | v2.0（新设计） |
|------|-------------|----------------|
| **页面标题区** | 白底黑字 + 左红竖线 | **深色渐变横幅**（深灰→稍亮），标题白字 + 红色副线 + 右上角微光粒子效果 |
| **主表单卡片** | 纯白 `#FFF` 圆角卡 | **毛玻璃卡片** `rgba(255,255,255,0.72)` + `backdrop-filter:blur(12px)` + 顶部 2px 红色渐变边（`accent-gradient`） |
| **文本输入框** | 白底 + 灰边 | 白底 + 更粗的聚焦环（红光晕 `focus-glow`） |
| **字数统计** | 灰色小字 | 红色进度条样式（已用/总数） |
| **模式切换按钮组** | 红底白字激活态 | **红底激活态 + 未选中态用毛玻璃**（`rgba(255,255,255,0.5)` + hover 变亮） |
| **「开始匹配」按钮** | 纯红 `#C7000B` | **红渐变** (`#C7000B → #E02020`) + hover 时 `brand-glow-strong` 光晕扩散动画 |
| **统计卡片**（底部） | 小号灰色数字 | **带图标的迷你数据卡**，图标用品牌色，数字用深色大字 |

**动效要求**：
- 表单卡片入场：`fadeInUp` 0.4s ease-out
- 「开始匹配」按钮：hover 时微微放大 1.02 + 光晕脉动（`box-shadow` pulse）
- 匹配模式切换：点击时按钮有 0.2s 弹性缩放（`scale(0.96) → scale(1)`）

### 3.2 竞品分析页（#page-competitor）

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **竞品卡片** | 白底 | 毛玻璃底 + **左侧品牌色竖线**（不同厂商不同颜色，华为=红） |
| **对比表格** | 斑马纹白/灰 | 冷灰斑马纹（`#E8EAED` / `#DEE1E6`）+ 行 hover 高亮 |
| **跟进按钮** | 默认蓝色/灰色 | 品牌红系（主操作红、次操作描边红） |

**动效要求**：
- 竞品列表项 stagger 入场（每项延迟 60ms）
- 卡片 hover 时微微浮起（`translateY(-2px)` + shadow 加深）

### 3.3 产品图谱页（#page-products）

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **图谱容器** | 白底 | **极淡的网格背景**（CSS `background-image: radial-gradient` 点阵） |
| **产品节点** | 白色小卡片 | **毛玻璃节点** + hover 时品牌色发光边缘 |
| **连接线** | 灰色细线 | 保持不变（已有） |

**动效要求**：
- 产品节点点击展开时弹性缩放
- 连接线绘制动画（可选，性能优先则跳过）

### 3.4 数据仪表盘（#page-dashboard）

**这是最需要视觉冲击力的页面。**

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **Hero 区域** | 已有红渐变（好） | **增强**：加噪点纹理 + 底部波浪 SVG 分割线 + 浮动光点动画 |
| **统计卡片（4格）** | 白底 | **深色半透明卡片**（`rgba(20,22,43,0.6)`）+ 白色文字 + 数字用等宽字体 + 每张卡左上角有品牌色小三角装饰 |
| **图表区域** | 白底 | **深色画布**（`#1a1d27`）+ 图表线条用品牌红 + 区域填充用 `rgba(199,0,11,0.1)` |

**动效要求**：
- 统计数字：计数动画（0 → 目标值，1.5s ease-out）
- Hero 区域：背景渐变缓慢位移动画（`background-position` 循环移动）
- 图表：绘制动画（线条从左到右生长）

### 3.5 历史记录页（#page-history）

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **记录列表** | 白色卡片堆叠 | **时间线式布局**（左侧竖线 + 圆点日期 + 右侧毛玻璃卡片） |
| **空白状态** | 灰色文字居中 | **插画 + 引导文案**（可后续加） |

**动效要求**：
- 记录项 hover 时右侧显示快捷操作按钮（slide-in）
- 删除时有淡出 + 缩小动画

### 3.6 成就中心页（#page-achievements）

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **成就卡片** | 白底 | **渐变底色卡片**（根据成就等级：金/银/铜 → 不同色调）+ 锁定态变灰 + 解锁时有闪光动画 |
| **进度条** | 灰色填充 | 品牌红填充 + 发光末端 |

**动效要求**：
- 成就解锁时：`scale` 弹跳 + 金色/红色光环扩散
- 进度条填充动画（width 0% → N%，0.8s ease-out）

### 3.7 知识库管理页（#page-knowledge）

| 区域 | v1.0 | v2.0 |
|------|------|------|
| **文档列表** | 白色表格 | **条纹化表格**（交替行用不同透明度）+ 行 hover 高亮 |
| **编辑器弹窗** | 白底模态框 | **深色模态框**（`#1B1E36`）+ 白色文字 + 红色强调按钮 |

### 3.8 设置页（#page-settings）

| 区域 | v1.0 | v2.0 |
|------|------|------|

## 4. 组件级规范（通用）

### 4.1 按钮

```
┌──────────────┬──────────────┬──────────────┐
│  主要按钮     │  次要按钮     │  幽灵按钮     │
│  (Primary)   │  (Secondary) │  (Ghost)     │
├──────────────┼──────────────┼──────────────┤
│ 红渐变底     │  毛玻璃白底   │  透明底       │
│ 白字         │  红字+红边    │  红字无边     │
│ hover:光晕   │  hover:填满红 │  hover:淡红底 │
│              │              │              │
│ [ 开始匹配 ] │ [ 清空 ]     │ [ 取消 ]     │
└──────────────┴──────────────┴──────────────┘
```

### 4.2 表单输入框

- 默认：白底 + `1px solid #D1D5DB`
- 聚焦：`2px solid #C7000B` + 外圈红光晕 `0 0 0 3px rgba(199,0,11,0.12)`
- 占位符：`#8890A4`
- 文本：`#1A1C23`

### 4.3 卡片（通用）

```css
.card {
    background: rgba(255, 255, 255, 0.72);
    backdrop-filter: blur(12px);
    -webkit-backdrop-filter: blur(12px);
    border: 1px solid rgba(255, 255, 255, 0.45);
    border-radius: 14px;
    box-shadow: 0 4px 24px rgba(0, 0, 0, 0.06),
                0 1px 3px rgba(0, 0, 0, 0.04);
}
.card:hover {
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.10),
                0 2px 8px rgba(199, 0, 11, 0.06);
    transform: translateY(-1px);
}
```

### 4.4 表格

- 表头：`#DEE1E6` 底 + 深色字 `#1A1C23` + font-weight 600
- 行：交替 `transparent` / `rgba(0,0,0,0.02)`
- 行 hover：`rgba(199, 0, 11, 0.04)` 淡红高亮
- 边框：`rgba(0,0,0,0.05)` 细线

### 4.5 Modal / 弹窗

- 背景遮罩：`rgba(0, 0, 0, 0.5)` + backdrop blur
- 弹窗本体：`#FFFFFF` （弹窗保持纯白以保证内容清晰度）
- 关闭按钮：右上角圆形，hover 变红

### 4.6 Toast / 通知

- 成功：绿色 + check 图标
- 错误：红色 + x 图标
- 信息：蓝色 + i 图标
- 入场：从右上方 slide-in + fadeIn
- 出场：fadeOut + slideOut

## 5. 全局动效清单

| 动效名称 | 应用位置 | 时长 | 缓动函数 |
|---------|---------|------|---------|
| **fadeInUp** | 页面切换/卡片入场 | 0.4s | cubic-bezier(.16,1,.3,1) |
| **staggerIn** | 列表项依次入场 | 每项+60ms | ease-out |
| **scalePop** | 按钮/节点点击 | 0.2s | cubic-bezier(.34,1.56,.64,1) |
| **glowPulse** | CTA按钮hover光晕 | 1.5s loop | ease-in-out |
| **slideRight** | 操作按钮reveal | 0.25s | ease-out |
| **countUp** | 仪表盘数字 | 1.5s | ease-out |
| **progressFill** | 进度条/成就条 | 0.8s | ease-out |
| **modalFade** | 弹窗开关 | 0.25s | ease-in-out |

> 性能原则：所有动画使用 `transform` 和 `opacity`（GPU加速），避免触发 layout/paint。

## 7. 验收标准（DoD）

1. **内容区不再是白色** —— 截图中能明显看出是**冷灰色底**而非白色
2. **卡片有层次感** —— 毛玻璃/阴影/边框至少具备两项
3. **品牌色贯穿全场** —— 不只侧边栏，内容区的按钮/激活态/装饰都有红色
4. **至少 3 种可见动效** —— 页面切换/按钮hover/卡片入场
5. **全部功能正常** —— 零回归（沿用 AUDIT_REPORT 基线）
6. **移动端正常** —— ≤767px 下不崩、不遮挡、可操作
