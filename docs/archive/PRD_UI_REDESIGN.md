# 华为云解决方案智能匹配系统 — UI 重设计 PRD（v1.0）

> 文档状态：待评审（用户确认后进入开发）
> 设计方向：**企业控制台风**（深色导航框架 + 浅色内容区 + 华为红品牌点缀）
> 原则：**换皮不换骨** —— 仅重构 UI/UX 与视觉语言，所有现有功能、接口、数据零改动

---

## 0. 背景与目标

当前线上版（cloudsol.cn）已完成浅色化 + 华为红增强改造，但用户反馈：
- "看着一坨大便"：深色弹窗残留、图标丢失等体验 bug（已在本地修复）
- "太素"：纯白卡缺乏层次与品牌性格

本 PRD 重新定义统一的**企业控制台视觉语言**，以「深色框架 + 浅色内容 + 华为红品牌」彻底告别全白，覆盖全部 9 个页面/模块，输出规范供开发落地。

---

## 1. 设计目标与原则

| 目标 | 说明 |
|------|------|
| **大厂质感** | 对齐华为云 / Azure / 阿里云企业控制台观感，专业、可信 |
| **可读性优先** | 长文（方案、竞品对比）在浅色内容区阅读，深色仅用于导航框架 |
| **品牌性格** | 华为红 `#C7000B` 作为唯一品牌主色，贯穿操作/激活/关键数据 |
| **层次分明** | 通过"深色框架 / 浅灰底 / 白卡 / 品牌色"四级对比建立空间秩序 |
| **零功能丢失** | 所有端点、DOM、交互保留，仅视觉与布局优化 |

**设计原则**
1. 深色仅用于"框架"（侧边栏 + 顶栏），内容区一律浅色 —— 避免长文疲劳。
2. 华为红只做"点睛"，不铺满；大面积用中性灰阶，保证专业克制。
3. 所有可点击元素有明确的 hover / active / focus 三态反馈。
4. 数据可视化用统一调色板（红蓝绿金紫），避免随机配色。

## 2. 设计系统（Design System）

### 2.1 布局架构（Layout）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 TOPBAR（深色 #14162B）                                      │
│ [☰] cloudsol │ [全局搜索…………]      🔔通知   guoguo ▾  ⚙      │
├────────────┬─────────────────────────────────────────────────┤
│ 侧边栏      │  内容区 CONTENT（浅灰 #F0F2F5）                    │
│ SIDEBAR     │  ┌──────────────────────────────────────────┐   │
│ （深色）     │  │ 面包屑 / 页面标题（红竖线）    [操作按钮]   │   │
│ ● 方案匹配   │  └──────────────────────────────────────────┘   │
│   竞品分析   │  ┌────────┐ ┌────────┐ ┌────────┐             │
│   产品图谱   │  │ 白卡    │ │ 白卡    │ │ 白卡    │             │
│   数据仪表盘 │  └────────┘ └────────┘ └────────┘             │
│   知识库     │  ┌──────────────────────────────────────────┐   │
│   历史记录   │  │ 主内容块（白卡 / 表格 / 图谱）            │   │
│   成就       │  └──────────────────────────────────────────┘   │
│   设置       │                                                 │
└────────────┴─────────────────────────────────────────────────┘
```

- **侧边栏**：固定宽 `220px`（收起 `64px`），深色背景，一级导航 8 项 + 图标
- **顶栏**：高 `56px`，深色，含 Logo、全局搜索、通知、用户菜单、设置入口
- **内容区**：左右 padding `24px`，最大宽度不限（自适应），背景浅灰
- **移动端**：侧边栏转为底部 Tab 栏（7 项），顶栏保留精简版

### 2.3 字体排版（Typography）

- **字体栈**：`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif`
- **基准**：正文 14px / 行高 1.5 / `--text-1`
- **字号阶梯**：H1 24/600 · H2 20/600 · H3 16/600 · H4 14/600 · 正文 14 · 辅助 12
- **数字/数据**：等宽数字 `font-variant-numeric: tabular-nums`，KPI 数字用 28–32px/700

### 2.4 间距与栅格（Spacing & Grid）

- 8px 基准栅格：`4 / 8 / 12 / 16 / 24 / 32 / 48`
- 卡片内边距 `16–20px`，区块间距 `16–24px`
- 内容区栅格：12 列，断点 `≥1200` / `≥768` / `<768`

### 2.5 圆角与阴影（Radius & Shadow）

- 圆角：`sm 6 · md 8 · lg 12 · xl 16 · 圆形 999`
- 阴影：
  - `--shadow-card`：`0 1px 3px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04)`
  - `--shadow-hover`：`0 4px 12px rgba(0,0,0,.10)`
  - `--shadow-pop`：`0 8px 24px rgba(0,0,0,.12)`（弹窗/下拉）
- **红系专属**：主按钮阴影 `0 2px 8px rgba(199,0,11,.25)`

### 2.6 核心组件库（Component Library）

**按钮 Button**
| 类型 | 样式 |
|------|------|
| 主按钮 | 红底白字，hover 加深+上浮，focus 红环 |
| 次按钮 | 白底+边框，hover 浅红底 |
| 文字按钮 | 红字，无边框 |
| 危险 | 红边红字，hover 红底白字 |
> 统一高度 36（默认）/ 32（小）/ 40（大）；圆角 8

**输入框 Input**
- 白底、1px 边框、focus 时 `0 0 0 3px rgba(199,0,11,.12)` 红环
- 错误态红边 + 下方红字提示

**卡片 Card**
- 白底、圆角 12、`--shadow-card`、hover 轻微上浮
- 顶部可选 3px 品牌色线（区分板块）

**表格 Table**
- 表头浅灰底 `#F7F8FA`、行 hover 浅红底、分页器激活态红填充

**标签/徽章 Tag**
- 华为红浅底红字（主）、蓝/绿/金对应语义；圆角 6

**进度/步骤 Stepper**
- 激活态红、完成态绿勾、未完成灰；步骤条带 shimmer 动效

**弹窗 Modal / Drawer**
- 遮罩 `rgba(0,0,0,.45)`；弹窗白底圆角 16 + `--shadow-pop`
- 产品详情用 **底部 Drawer**（移动端）/ 右侧 Drawer（桌面）

**Toast**
- 顶部右侧滑入，左侧语义色竖条（成功绿/错误红/警告金）

**空状态 Empty**
- 居中图标 + 文案 + 主按钮引导

**导航 Nav（侧边栏）**
- 深色底；激活项：左侧 3px 红条 + 浅红底 + 白字；图标用线性 Lucide

### 2.7 动效规范（Motion）

- 卡片 hover：`transform translateY(-2px)` + 阴影加深，过渡 `0.2s ease`
- 页面切换：内容区 `fade + 8px 上移`，`0.25s`
- 侧边栏展开/收起：`0.2s`
- 弹窗：scale `0.96→1` + fade，`0.25s`
- 进度条/shimmer：加载态流动光效
- 原则：动效≤300ms，仅作"反馈"不抢戏

### 2.8 响应式（Responsive）

- `≥1200`：侧边栏常驻 220px，内容双/三栏
- `768–1199`：侧边栏可收起，内容单/双栏
- `<768`：侧边栏→底部 Tab 栏（7 项），顶栏精简，卡片单列堆叠

## 3. 逐页 PRD

> 每页结构：目标 → 信息架构/布局（线框） → 关键组件与视觉 → 交互 → 验收标准(DoD)

### 3.1 方案匹配页（solution）

**目标**：售前输入客户需求，生成华为云解决方案（标准/智能/向导三模式）。

**布局**
```
┌─ 内容区 ───────────────────────────────────────────┐
│ 方案匹配  |  [标准][智能][向导]  ← 模式切换(红激活)   │
├──────────────────────────────────────────────────┤
│  ┌─ 输入区(白卡,顶红线) ────────────────────────┐  │
│  │ 需求描述 textarea + [行业下拉][规模]          │  │
│  │ [开始匹配](红)  [清空]                        │  │
│  └──────────────────────────────────────────────┘  │
│  ┌─ 思考流(SSE,仅智能模式) ────────────────────┐  │
│  │ ● 分析需求 → ● 检索知识库 → ● 生成方案       │  │
│  └──────────────────────────────────────────────┘  │
│  ┌─ 结果区(白卡) ──────────────────────────────┐  │
│  │ 方案标题(红竖线)  来源文档(标签)  [导出Word] │  │
│  │ 结构化方案内容…                              │  │
│  └──────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

**关键组件与视觉**
- 模式切换：Segmented Control，激活态红底白字
- 输入区卡片顶部 3px 红线，textarea focus 红环
- 智能模式思考流：横向 Stepper，红/绿/灰三态 + shimmer
- 结果卡：标题左侧红竖线，来源文档用蓝/红 Tag，导出按钮红

**交互**
- 标准/智能共用输入框；向导模式点击后弹出 4 步抽屉（行业→规模→痛点→确认），合成需求回填输入框
- 智能模式实时 SSE 推送思考步骤
- 结果区支持导出 Word（已有端点 `/api/export/report`）

**DoD**
- 三模式均可触发匹配；向导抽屉关闭后正确回填；思考流实时渲染；导出可用；深色框架与红点缀到位

### 3.2 竞品分析页（competitor）

**目标**：输入需求，生成与指定竞品（AWS/阿里云等 12 家）的对比分析，支持追问与跟进。

**布局**
```
┌─ 内容区 ───────────────────────────────────────────┐
│ 竞品分析 | [需求输入] [竞品选择▼] [开始分析](红)    │
├──────────────────────────┬───────────────────────┤
│ 对比结果(白卡,可滚动)      │ 追问面板(白卡,顶红线)  │
│ ● 维度对比表格            │ 用户输入追问…          │
│ ● 优劣势标签(红蓝)        │ [发送](红)            │
│ ● 跟进建议                │ ── 对话历史 ──         │
│ [导出][保存跟进]          │                        │
└──────────────────────────┴───────────────────────┘
```

**关键组件与视觉**
- 竞品选择：多选下拉，选中项红 Tag
- 对比表：表头浅灰，华为列高亮浅红底，竞品列中性
- 优劣势：优势绿 Tag / 劣势红 Tag
- 追问面板：右侧独立卡，对话气泡（用户右/系统左），发送按钮红

**交互**
- 分析完成展示维度对比 + 优劣势；右侧追问实时调用 `/competitor/refine`
- "保存跟进"写入竞品跟进记录（现有功能保留）
- 移动端：追问面板折叠至结果下方

**DoD**
- 竞品选择/对比渲染/追问对话/保存跟进全部可用；华为列视觉突出；无功能丢失
