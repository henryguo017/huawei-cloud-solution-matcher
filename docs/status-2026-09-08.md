## 一、上一环节完成清单（2026-09-07 ~ 09-08，全部生产验证）

### 1. Agent 边界审计 + 三深根因修复（09-07）
- 离线覆盖：56 题意图矩阵 + 14 类对抗边界 probe（`tests/test_intent_coverage.py` / `tests/probe_edge_intents.py`）。
- 线上实测：16 题全量用例 16/16 通过。
- 修复三深根因（均已部署验证）：
  - **联网搜索静默空**（a6a5221）：`reset_web_search_budget()` 定义了但从未调用，进程级计数器跑满 limit=3 后永久禁搜 → 每轮 run() 首轮 reset。
  - **竞品自洽问题误澄清**（74a40c9）：指名道姓的竞品追问被 `_need_clarify` 拦截 → 自洽问题跳过澄清。
  - **两阶段末步 MCP 污染超时**（7d6793f）：综合生成步被注入 MCP 工具 → 模型调 match_history → ask 闸门阻塞 60-120s 级联超时 → 远端 MCP 工具只追加到动作步；同时只读 MCP 工具（cost_calc/cost_reference_list/match_history/client_list）加入免确认 allow 表。
- 意图正则补强（9cff9b1 / e7763f1）：`_DOC_INTENT_RE` 泛化动词+格式名词、`_CONFIRM_RE` 短确认升级、口语方案词、行业词保护、追问历史截断 500→2000/300→1500 字。

### 2. 知识库统计按登录态分口径（09-08，5114fc6）
- 排查结论：per-user 独立 KB 架构早已存在（`get_user_knowledge_base`，`data/user_docs/{user_id}/` 独立 ChromaDB，懒复制初始化），但 `/knowledge/stats` 写死读全局库 → 所有用户数字一样。
- 修复：该接口加可选鉴权——登录 → 用户自己 KB 实时统计（上传/删除后刷新即变）；未登录 → 全局（欢迎页营销数字不变）。
- 前端：`script.js` `API.getKnowledgeStats()` 带 Bearer 头；Agent 页脚未登录保持 `--` 占位（"登录后可见"文案上线后用户反馈效果不好，已回滚 8ef9833）。
- 生产验证闭环：journalctl 实锤 `user_id=0`（未登录）/ `user_id=2`（guo token）分流正确；guo 登录态 902、0.6s（用户库已初始化、无个人上传=与全局一致，符合预期）。
- 待收口：浏览器实测 guo 上传一篇 → 页脚 902→903。
